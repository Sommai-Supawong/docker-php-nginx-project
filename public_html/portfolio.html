04 / How I think

Code should work.
Interfaces should feel right.
Products should solve something.

01 Engineering

Clear responsibilities. Understandable structure. Build systems that are easier to maintain, change, and reason about.

02 Experience

The small details matter. Readability, feedback, and interaction should help people move forward with confidence.

03 Product thinking

Before adding a feature, ask what problem it solves. Start with the person using it, then choose the technology.

05 / A work in progress

Learn by making.

No perfectly straight path. Just a continuous loop of curiosity, practice, and refinement.

  1. Step 01

    Explore

    Follow a question. Try a new tool. Find something worth making.

  2. Step 02

    Build

    Turn an idea into a working project. Connect the pieces.

  3. Step 03

    Break

    Test assumptions. Meet the edge cases. Find the limits.

  4. Step 04

    Learn

    Understand what happened. Make the next decision better.

  5. Step 05

    Refine

    Simplify the system. Polish the experience. Start again.
